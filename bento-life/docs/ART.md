# 아트 가이드 — 그림책 파스텔

> 일러스트레이터에게 이 문서와 [`art-assets.csv`](art-assets.csv)(전체 그림 목록)를 같이 전달한다.

## 한 줄 방향
**"엄마아빠가 아이 몰래 쓴 육아 그림일기."**
오일 파스텔·크레파스로 그린 동화책 질감. 따뜻하고 조용하지만, 과잉보호 부모를 슬쩍 놀리는 유머가 있다.

## 레퍼런스

| 작품 | 가져올 것 | 가져오지 않을 것 |
|---|---|---|
| **Venba** (Visai Games) | 오일 파스텔 질감, 가장자리가 거칠게 번진 그림, 음식이 정말 맛있어 보이는 묘사, 움직임이 적은 한 장면 연출 | 굵고 각진 카툰 윤곽선 |
| **Florence** (Mountains) | 덜어낸 화면, 한 장면 = 한 시절, 대사 없이 그림만으로 감정 전달 | 만화 칸 나누기 (우리는 한 장에 한 장면) |
| 그림책 일반 | 종이 질감, 여백, 색연필로 덧칠한 그림자 | 아기 대상 그림책의 과장된 귀여움 |

## 핵심 원칙

1. **부모는 얼굴을 그리지 않는다.** 플레이어가 곧 부모다. 손, 도시락 가방, 뒷모습, 나무 뒤로 삐져나온 그림자 정도만 보인다. 성별도 드러내지 않는다.
2. **주인공은 아이와 도시락.** 모든 이벤트 그림에 도시락(가방, 통, 보자기)이 어딘가 들어가면 좋다. 숨은그림처럼 찾게 해도 좋다.
3. **유머는 표정과 상황으로.** "졸졸" 따라다니는 장면에서는 부모가 어설프게 숨어 있고(선글라스, 나무 뒤 등), 아이는 다 알고 있는 표정을 짓는다.
4. **어른이 보는 그림책.** 타깃은 20~40대 부모와 예비 부모다. 눈이 지나치게 크거나 볼이 빨간 '아기 앱' 스타일은 피한다.
   > 이유: 그림이 아동용처럼 보이면 Google Play가 아동 대상 앱으로 분류할 수 있고, 그러면 광고 수익 모델이 크게 제한된다.

## 색

게임 화면(`src/style.css`)과 같은 팔레트다. 그림도 이 안에서 고른다.

| 이름 | 밝은 모드 | 쓰임 |
|---|---|---|
| 종이 | `#f4ecdd` / 카드 `#fbf6ec` | 배경. 그림 배경도 순백 대신 종이색 |
| 잉크 | `#4a3b30` | 선과 글자. **순수 검정은 쓰지 않는다** |
| 토마토 | `#e0735a` | 주 강조색, 도시락통 |
| 머스터드 | `#e6b24f` | 햇빛, 계란, 따뜻한 순간 |
| 세이지 | `#8fb07a` | 채소, 건강, 좋은 결과 |
| 하늘 | `#7ea6c8` | 학교, 밤, 차분한 순간 |
| 자두 | `#b48cb9` | 사춘기, 고민, 저녁 |
| 장미 | `#e8a19c` | 볼, 첫사랑, 유대감 |

어두운 모드(밤의 그림책, 배경 `#23253a`)에서도 그림은 그대로 쓰므로, 그림 자체 배경이 너무 하얗지 않게 한다.

## 선과 질감
- 윤곽선: 잉크 갈색, 굵기가 고르지 않은 크레파스 선. 없어도 된다.
- 채색: 평면 채색 + 크레파스·파스텔 결. 그라데이션은 최소로.
- 그림자: 한 단계만, 색연필로 빗금 친 느낌.
- 가장자리: 이벤트·엔딩 그림은 사각 프레임을 꽉 채우되, 게임이 모서리를 울퉁불퉁하게 잘라 주므로 바깥 2~3%에는 중요한 걸 두지 않는다.

## 종류별 규칙

### 아이 초상 `characters/` (512×512, 투명 배경)
- 가슴 위로 정면에서 약간 비스듬히. 동그란 틀로 잘려서 쓰이므로 얼굴은 가운데 70% 안에 둔다.
- 6시기 × 성별 2 × 표정 4 (기본, 신남, 시무룩, 질색). 출시에는 **기본 표정 12장**만 있어도 된다 (없는 표정은 기본 표정으로 대체됨).
- 같은 아이가 자라는 것처럼 보이게, 시기가 바뀌어도 머리색·눈매·점 같은 특징을 유지한다.

### 재료 `ingredients/` (256×256, 투명 배경)
- **화면에서 약 40px로 줄어든다.** 단순한 형태, 확실한 밝기 대비, 하이라이트 하나. 질감은 아주 약하게.
- 위에서 45°로 내려다본 각도로 통일한다 (도시락 칸에 담긴 느낌).
- 김밥 몇 조각, 계란말이 두 조각처럼 "도시락에 담긴 양"으로 그린다.

### 이벤트 `events/`, 엔딩 `endings/` (1200×900, 4:3)
- 한 장면 = 한 순간. 정지 그림이고, 화면 위쪽 카드에 들어간다.
- 아이 체형 기준: 영아 2등신, 유아 3, 초등 4, 중등 5, 고등 6, 스무 살 7등신.
- 성별이 랜덤이므로 이벤트 그림의 아이는 **뒷모습, 실루엣, 작게 보이는 구도** 등으로 성별이 두드러지지 않게 하거나, 남녀 두 장을 그린다. 파일 이름 뒤에 `-boy`/`-girl`을 붙이면(예: `events/crush-girl.webp`) 그 성별일 때 우선 쓰인다.
- 나이별 이벤트(P0, 20장)는 큰 장면, 랜덤 이벤트(P1, 15장)는 소품 위주의 작은 장면이어도 된다.

## 파일 넣는 법
1. `art-assets.csv`의 경로 그대로 `src/assets/art/` 아래에 저장한다. 예: `src/assets/art/events/picnic.webp`
2. 형식은 **WebP** 권장(PNG도 됨). 같은 이름이면 webp가 우선이다.
3. `npm run dev`로 확인한다. 파일이 있으면 자동으로 그림이, 없으면 이모지가 나온다.
4. `npm run gen:art`를 실행하면 CSV의 '완료' 칸이 채워진다.

## 제작 진행 제안
1. **스타일 테스트 (3~5장):** 8살 소풍 이벤트 1장 + 초등학생 아이 기본·신남 표정 2장 + 재료 3개(김밥, 계란말이, 브로콜리). 게임에 넣어 실제 크기로 확인한 다음 본 작업에 들어간다.
2. **출시 세트 P0 (75장):** 기본 표정 12, 재료 28, 나이별 이벤트 20, 엔딩 12, 로고 1, 스토어 아이콘·대표 이미지 2
3. **업데이트 P1 (52장):** 표정 36, 랜덤 이벤트 15 등
4. 외주 계약 시 **상업적 이용, 수정·가공, 스토어·SNS 홍보물 사용 범위**를 계약서에 명시한다.
