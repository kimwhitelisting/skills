# Play 스토어 등록 초안

> 초안이다. 이름·설명은 바꿔도 되고, 설문 답은 마지막에 실제 기능(광고 등)에 맞춰 다시 확인한다.

## 이름 (최대 30자)
**도시락 육아** — 부제 후보: 「도시락 육아: 졸졸 따라다니기」

## 짧은 설명 (최대 80자)
도시락 싸들고 졸졸 따라다니면, 아이를 얼마나 잘 키울 수 있을까? 1살부터 스무 살까지 도트 육아 시뮬레이션.

## 자세한 설명 (최대 4000자)
```
도시락 싸들고 졸졸 따라다니면, 아이를 얼마나 잘 키울 수 있을까?

매일 아침, 아이가 오늘 사정을 말해요.
"오늘 체육 있어!" "시험이야…" "…아무거나."
주식·메인·반찬 세 칸을 채워 도시락을 싸 주세요. 아이의 취향은 먹여 봐야 알아요.

그리고 선택의 순간.
믿고 보낼까요, 몰래 따라가 볼까요?
나무 뒤, 전봇대 뒤에 숨어 등굣길을 따라가요. 아이가 뒤돌아보면 얼음!
가까이 있을수록 ♥가 쌓이지만, 들키면… 사춘기 아이는 오래 기억해요.
위기의 순간, 달려갈지 참을지도 당신의 몫이에요.

■ 1살부터 스무 살까지
아기 이유식부터 야자 도시락, 마지막 도시락까지. 아이는 8단계로 자라고, 키는 해마다 기린 키재기에 새겨져요.

■ 52가지 엔딩
명의, 국가대표, 고양이 의사… 그리고 "평생 도시락 받는 어른", "부모 도시락을 디스하는 인디 밴드", "사진집 「뒤에서 본 부모」".
항상 해피엔딩일 수는 없어요. 스무 살이 되기 전에 끝나는 이야기도 있어요.

■ 90가지가 넘는 이벤트
돌잡이, 첫 소풍, 방문이 닫힌 날, 형광 분홍 머리, 첫사랑, 수능 날 아침…
하트 상점에서 강아지·피아노·필름 카메라 같은 이야기 꾸러미를 열면 새 이야기가 시작돼요.

■ 해마다 한 장, 사진첩
그해의 한 장면이 폴라로이드로 남아요. 스무 장을 다 모으면 한 아이의 앨범이 완성돼요.

■ 600가지 도시락 메뉴 도감
재료 조합마다 이름이 있는 메뉴, 숨은 특별 메뉴까지.

과잉보호와 방임 사이, 정답 없는 육아를 도시락 하나로 웃으며 겪어 보세요.
```

## 분류 · 태그
- 카테고리: **게임 › 시뮬레이션** (대안: 캐주얼)
- 태그 후보: 육아, 인생 시뮬레이션, 도트, 픽셀, 힐링, 수집

## 앱 콘텐츠 설문 — 답변 초안
| 항목 | 초안 | 메모 |
|---|---|---|
| 타깃 연령 | **18세 이상** (부모 · 성인) | 아동이 포함되면 가족 정책·광고 제한. 그림체가 귀여워도 대상은 부모 |
| 광고 포함 | 지금은 **아니요** → 광고를 붙이면 **예** | |
| 콘텐츠 등급 (IARC) | 폭력: 가벼운 부상 묘사(교통사고로 다침, 피 없음) · 담배 언급(교복에서 담배 냄새) · 연애(손 잡기 수준) · 가상 결제/도박: 없음(코인·현질은 이야기 속 사건) · 사용자 간 소통: 없음 | 12세 이용가 정도로 예상 |
| 데이터 보안 | 수집·공유하는 데이터 **없음** (모든 저장은 기기 안) | 광고를 붙이면 "기기 또는 기타 ID — 광고" 추가 |
| 개인정보처리방침 URL | `privacy-policy.md`를 웹에 올린 주소 (GitHub Pages 등) | 필수 |
| 정부 앱 · 뉴스 앱 · 금융 기능 | 아니요 | |
