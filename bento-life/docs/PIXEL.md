# 도트 그림 — 어떻게 만들었나

이 게임의 그림은 **전부 코드로 찍은 도트**다. 이미지 파일을 그려서 넣는 대신, 칸(픽셀)에 색을 찍는 작은 엔진(`src/pixel/`)으로 아이·재료·배경·소품을 그리고 장면마다 조립한다.
사람이 손으로 다듬고 싶은 부품만 PNG로 바꿔 끼울 수 있다.

> 예전 방향(그림책 파스텔 + AI 일러스트)은 [`ART.md`](ART.md)에 남아 있다. 지금 게임은 쓰지 않는다.

## 왜 도트를 코드로

| 문제 | 도트를 코드로 그리면 |
|---|---|
| 첫 시제품이 "웹 화면 같다" (박스·격자·이모지) | 굵은 외곽선 패널 + 도트 장면 한 가지 세계로 통일되어 게임처럼 보인다 |
| AI로 사람 그림을 뽑으면 장마다 얼굴·옷이 조금씩 다르다 | 같은 규칙으로 그리니 0살부터 스무 살까지 **같은 아이**로 보인다 |
| 그림 작업은 토큰·시간·돈이 많이 든다 | 무료. 이벤트를 추가할 때 장면도 코드 몇 줄로 같이 만든다 |
| 걷기 애니메이션은 프레임이 많이 필요하다 | 걷는 자세를 수식으로 계산해 8프레임을 자동으로 뽑는다 |
| 손그림의 맛이 아쉽다 | 부품을 PNG로 뽑아 사람이 고친 뒤 같은 이름으로 넣으면 그 부품만 바뀐다 |

## 엔진 (`src/pixel/`)

| 파일 | 하는 일 |
|---|---|
| `grid.ts` | 칸 격자 `Grid`: `set`·`rect`·`hline`·`vline`·`ellipse`(반 칸 보정)·`stamp`(문자 그림)·`draw`(겹치기, 좌우 뒤집기)·**`outline`**(빈칸 중 칠한 칸과 맞닿은 곳을 외곽선 색으로). `recolor`(팔레트 바꾸기), `scale2x`, `rotsprite`(회전), `toDataURL` |
| `palette.ts` | 색 `P` 한 벌. 따뜻한 그림책 색을 작은 크기에서도 또렷하게 조금 진하게. 모든 그림이 이 안에서 고른다 |
| `child.ts` | 아이 생성기 (아래 "아이") + 얼굴 없는 부모 실루엣 `parentSide` |
| `foods.ts` | 재료 28종 16×16 아이콘 (문자 그림) |
| `scenes.ts` | 부엌 벽·조리대, 등굣길 거리 조각, 나무, 전봇대, 도시락통(칸 좌표 포함), 뚜껑+보자기 |
| `extras.ts` | 강아지, 이웃 할머니, 학교 건물, 현관 벽·바닥, 바닥에 놓인 작은 도시락 |
| `event-scenes.ts` | 이벤트 68개·엔딩 39개 장면 조립 (아래 "장면") |
| `fx.ts` | 하트·반짝임·먼지·별 파티클, 머리 위 말풍선(`!` `…` `♪`) |
| `sprite-cache.ts` | Grid → 캔버스 캐시. 같은 그림은 한 번만 그린다 (키에 나이·성별·표정·프레임) |
| `font.ts` | 도트 글꼴 갈무리11 등록 |
| `parts-loader.ts` | 사람이 고친 부품 PNG를 읽어 코드 그림 대신 쓴다 |

### 화면에 찍는 규칙
- 장면은 **논리 크기 110칸 폭**으로 그리고, 화면 폭에 맞는 **정수 배율**로만 키운다 (`image-rendering: pixelated`). 360~412px 폰에서 3배.
  - 부엌·현관·결산: 110×98 / 이벤트·엔딩: 110×72 / 등굣길: 1칸 = 3px, 높이 100~128칸
- 외곽선은 그림을 다 겹친 뒤 **맨 마지막에 한 번** 씌운다 (부품마다 그리면 겹치는 곳이 두꺼워진다).
- 결산·엔딩의 큰 아이는 캔버스에서 2배로 (`imageSmoothingEnabled = false`).

## 아이 (`child.ts`)

**층(레이어)을 따로 그려 겹친다:** 다리 → 옷 → 머리(피부) → 머리카락 → 얼굴 → 소품 → 외곽선.
머리는 피부와 머리카락을 한 번에 그린 뒤 색으로 둘로 나눈다 (`splitHead`). 그래서 머리카락만 따로 고치거나 바꿀 수 있다.

### 성장 7단계 (`PX_AGES`, `pxAgeOf(나이)`)
| 단계 | 나이 | 옷 | 체형 |
|---|---|---|---|
| 1 | 0–1 | 우주복 + 턱받이, 양말 발 | 머리 크고 다리 3칸 |
| 4 | 2–5 | 노란 원복 + 이름표 | |
| 7 | 6–9 | 흰 티(남)·노란 원피스(여) + 책가방 끈 | |
| 11 | 10–12 | 줄무늬 티(초록·보라), 긴 바지(남)·치마(여) | |
| 15 | 13–15 | 중학교 교복(남색) + 넥타이·리본, 목 | |
| 18 | 16–18 | 고등학교 블레이저 + 흰 셔츠, 체크 치마(여) | 머리 작고 다리 10칸 |
| 19 | 19 | 사복: 셔츠(남)·카디건과 긴 치마(여) | |

- **발끝은 모든 단계에서 같은 줄(38)** 에 닿는다 (`legTop + legH = 38`). 키가 크면 머리가 위로 올라간다 → 결산 문기둥 눈금이 해마다 올라가는 이유.
- **같은 아이로 보이게 하는 규칙**: 여자아이 = 밤색 머리 + 머스터드색 핀, 남자아이 = 진갈색 + 정수리 뻗친 머리, 둘 다 왼쪽 눈 밑 점. 아기 때 핀·뻗친 머리 몇 가닥부터 시작해 18살 이후엔 머리가 조금 길어진다.
- 표정 5종: `neutral` `happy` `yuck` `sad` `surprise` + 눈 깜빡임. 11살까지는 눈에 하이라이트, 7살까지는 볼터치.
- 정면 `childFront`와 옆모습 걷기 `childSide`(오른쪽을 봄).
- 확인용 시트: `npx vite-node scripts/sheet-stages.ts out.png`

### 걷기 8프레임 (`walkPose`)
한 주기를 8장으로 나눠 다리가 앞뒤로 엇갈리고(`swing`), 두 다리가 지나치는 순간 몸이 1칸 올라가고(`bob`) 앞으로 나가는 발이 1칸 들린다. 팔은 다리와 반대로. **프레임은 시간 대신 걸은 거리로** 넘긴다 (미끄러지듯 걷는 느낌 방지).

### 옷 색·소품
- 옷 색 바꾸기: 정해진 옷 색을 다른 색으로 바꾸는 팔레트 교체 (`OUTFITS`: mint, berry, sky, raincoat). 친구 캐릭터는 반대 성별 + mint.
- 머리 소품 `HatId`: crown, gradcap, cap, raincap, chef, shades(선글라스). 머리 꼭대기(`headTop`)에 붙어서 어느 나이든 맞는다.
- 머리 기울이기: 머리 층만 RotSprite 방식(2배 확대를 3번 → 회전 → 축소)으로 돌려 외곽이 덜 깨진다.
- 염색: 장면에서 머리카락 색만 `recolor`로 바꾼다 (이벤트 「형광 분홍 머리」, 엔딩 「타투이스트」).

## 사람이 고친 부품 끼우기 (PNG 왕복)
**가장 쉬운 길: 도트 부품 작업대** (`npm run dev` → `/proto-parts.html`, 또는 미리보기 링크). 단계·성별·방향·부품을 고르고 「원본 받기」 → 편집기로 고치기 → 「고친 PNG 올리기」(또는 끌어다 놓기). 표정 5개·눈 깜빡임·걷기·이벤트 장면 속 모습이 바로 바뀐다. 크기가 24×40이 아니면 거절한다. 올린 부품은 그 기기에 저장되고, 다 되면 같은 이름으로 `src/assets/pixel/parts/`에 넣는다.

1. `npm run export:parts` → `art-src/pixel-parts/<방향>-<단계>-<성별>-<부품>.png` (490개, 1배·투명·외곽선 없음) + `_preview/` 8배 확대본.
2. 도트 편집기(무료 Pixelorama·LibreSprite·Piskel, 유료 Aseprite)로 고친다. **캔버스 크기 24×40·위치 그대로, 외곽선은 그리지 않음.**
3. 같은 이름으로 `src/assets/pixel/parts/`에 넣으면 게임이 그 부품만 바꿔 쓴다. 외곽선·옷 색 바꾸기·소품·걷기 흔들림은 코드가 계속 처리.
- 자세한 규칙: [`art-src/pixel-parts/README.md`](../art-src/pixel-parts/README.md). 테스트가 "모든 층을 같은 키로 바꿔 끼울 수 있는지" 확인한다.

## 장면 (`event-scenes.ts`)
이벤트·엔딩마다 그림을 따로 그리지 않고 **부품 상자에서 꺼내 조립**한다. 아이는 그 해의 단계로 들어가고, 고른 결과에 따라 표정만 바뀐다.

- **배경**: 아이 방(침대·책상·창문, 비·밤 변형), 교실(칠판·게시판·책상), 공원(트랙·만국기), 무대(커튼·조명), 마트 진열대, 병원, 밤의 학교(불 켜진 창), 부엌(조리대 앞층 따로), 현관, 골목길
- **소품**: 돌상, 케이크, 풍선, 연애편지, 휴대폰, TV·게임패드, 이정표, 수능 달력, 여행 가방, 고양이, 봉투·지폐, 이젤, 체온계, 출입금지 문, 기타, 마이크, 삼각대 카메라, 코인 차트, 비행기, 버스, 투표함, 이삿짐, 쓰레기통, 라면 냄비, 성적표, 체중계, 연기
- **인물**: 아이, 친구, 얼굴 없는 부모(플레이어 = 부모라서 얼굴을 그리지 않는다), 선생님, 할머니
- **기호**: 하트, 화남 표시, 땀, 음표, 반짝 별
- **색감**: `tint(장면, 색, 비율)`로 밤·노을 분위기 (모든 칸을 한 색 쪽으로 섞기)
- 조립 도우미: `put(장면, 그림, x, 발끝y)` 발끝 기준 얹기, `kidBehind` 조리대 너머 아이(어느 나이든 머리·어깨가 보이게), `headOnly` 베개·보자기용 얼굴

**이벤트·엔딩을 추가하면** `SCENES` / `ENDING_SCENES`에 한 줄을 꼭 넣는다 — 없으면 테스트가 실패한다. 기본 표정(`expr`)도 같이 정한다.
확인용 시트: `npx vite-node scripts/sheet-events.ts out.png [단계] [성별]`, `npx vite-node scripts/sheet-endings.ts out.png [성별]`

## 화면 틀 (`src/proto/pixel-ui.css`, `day-px.css`, `src/game.css`)
- 굵은 외곽선(3px) 패널, **눌리면 쑥 들어가는 버튼**(아래 그림자 → 누르면 0), 각진 게이지, 모서리 둥글림 없음
- 글꼴: 갈무리11 (도트 한글 글꼴, OFL-1.1, `npm i galmuri`)
- 색은 도트 팔레트와 같은 따뜻한 크림·잉크·토마토·머스터드·세이지 한 벌로 고정 (다크 모드 없음)

## 레퍼런스와 도구

| 이름 | 무엇 | 가져온 것 / 상태 |
|---|---|---|
| **pixelfx** (patch-gg.github.io/pixelfx, 오픈 소스) | 도트 이펙트 만들기 도구 (공유받음) | 도트 방향을 정한 계기. 파티클을 칸 단위로 찍는 방식(`fx.ts`)을 참고. 외부 코드 설치는 자동 권한 검사에서 막혀서 넣지 않았다 — 허용하면 붙일 수 있다 |
| **codixel** (공유받은 대화) | 코드로 도트를 찍는 접근 | "그림 파일 대신 코드로 찍는다"는 방향 그대로. 저장소 복제는 같은 이유로 하지 않았다 |
| **RotSprite** (Xenowhirl) | 도트 그림 회전 알고리즘 | 2배 확대 3번 → 회전 → 축소. `grid.ts`의 `rotsprite` |
| **Scale2x / EPX** (AdvanceMAME) | 도트 그림 2배 확대 | RotSprite 앞 단계. `scale2x` |
| **팔레트 교체** (고전 게임 기법) | 같은 그림의 색만 바꾸기 | 옷 색, 친구, 염색 |
| **층별 캐릭터 조립** (드레스업·아바타 게임 방식) | 부품을 겹쳐 캐릭터 만들기 | 아이 7단계 + 부품 PNG 교체 |
| **갈무리** (quiple, OFL-1.1) | 도트 한글 글꼴 | 화면 전체 글꼴 |
| **Pixelorama · LibreSprite · Piskel** (무료) / **Aseprite** (유료) | 도트 편집기 | 부품 PNG를 사람이 고칠 때 |
| **PixelLab** (유료, 선택) | AI 도트 생성 | 쓰지 않음. 코드 그림의 품질이 부족하다고 느껴질 때만 검토 |
| 동료 공유 문서·대화 (Tripo·Grok, HTML 파이프라인 등) | 참고만 | 저장소에 옮기지 않았다 |

### 돈이 드는 것
지금까지 그림에 쓴 돈은 0원이다. 유료가 될 수 있는 건 Aseprite(편집기, 선택)와 PixelLab(AI 도트, 선택)뿐이고 둘 다 없어도 된다.
