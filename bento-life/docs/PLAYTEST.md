## BENTO-QA-002 — 결산 사진·화면 대비 (2026-11-06)

Owner가 실제 플레이에서 지적했다. QA-001은 진행·뒤로가기에 치우쳐 결산 직후 수집 상태와 다크 모드의 시각적 문제를 놓쳤다. 자동 플레이 테스트는 DOM·사진첩 동기화·CSS 가독성을 보증하지 않는다.

### 수정과 재현

- 결산에 사진이 보이는데 사진첩의 올해 칸은 `…`였다. 저장이 다음 생일 버튼에만 연결되어 있었다. 결산을 처음 표시할 때 이번 생/수집에 즉시 한 번 저장한다. 기존 결산 저장을 이어해도 반영된다. 사진의 옷/모자·문구는 촬영 시점으로 고정하고 이후 렌더/다음 생일에서 중복 추가하지 않는다.
- 본 게임은 밝은 도트 팔레트지만 공용 CSS의 dark `--paper`/`--sheet`를 상속했다. 선택 탭은 갈색 바탕에 남색 글자, 비선택 탭은 남색 바탕에 갈색 글자였다. 공용 표면·보조 글자·강조 토큰을 게임 범위에서 고정했다.
- 주 버튼은 짙은 빨강으로 대비를 높였다. 비활성 버튼은 갈색 글자와 점선 테두리, 보조 설명은 짙은 갈색으로 구분한다. 하트 버튼 글자도 짙은 빨강으로 조정했다.

### 실제 UI 확인

- 격리한 390×700 브라우저에서 수정 전 1살 결산→사진첩 빈 칸/어두운 탭을 재현했다.
- 같은 저장을 수정본에서 이어하기: 다음 생일 전 1살 사진 등장, 수집 16→17, 확대 문구가 결산과 일치. 기존 돈25·하트99 보존.
- 2살까지 진행 후 다음 생일 전 사진첩에 1살·2살 각각 표시, 올해 사진 확대 문구 일치. 재접속 후 두 장 유지, 중복 없음. 수집은 장면 ID 기준이라 같은 장면을 다시 얻으면 총수 증가가 없는 것이 정상이다.
- 사진첩/메뉴/설정 고급 선택 버튼/상점/아침 재료 탭과 비활성 주 버튼을 화면·계산된 색으로 확인했다.
- 별도 테스트 HTML의 `data-theme=light`와 `dark`에서 설정 탭의 계산된 색이 동일함을 확인했다. 사용자 기기의 화면 모드를 변경하지 않았다.
- 선택 탭 대비 10.70:1, 비선택 12.69:1, 주 버튼 약4.99:1, 비활성 버튼 약6.96:1. 메뉴의 보조 설명과 닫기 버튼도 읽히는 것을 확인했다. 이 수치는 확인한 고정 배경/글자 쌍이며 전체 접근성 인증을 뜻하지 않는다.
- 기존 27개 테스트·2000판 자동 플레이, TypeScript/Vite 및 preview 빌드, Android debug 빌드·서명 검증 통과. Claude 읽기 전용 검토에서 차단 문제 없음.

### 다음 변경에도 확인할 화면 체크

1. 결산 도달 **직후**, 다음 생일을 누르기 전에 이번 생·수집·메뉴 수량·사진 확대가 일치하는지 본다.
2. 새로고침→이어하기, 다음 해 결산에서 저장 보존과 중복 여부를 본다.
3. 밝은/어두운 테마의 상속, 탭 선택/비선택, 버튼 활성/비활성, 작은 설명 글자를 실제 화면과 계산된 색으로 점검한다.
4. 게임 규칙 테스트, 브라우저 UI, 실제 기기 검증 결과를 별도로 기록한다. iPhone Safari 재확인과 native 기기 검증은 아직 별도다.
