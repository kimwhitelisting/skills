# 플레이 검증과 버그 수정

## BENTO-QA-001 — 2026-11-06

Codex 단일 구현, Claude 읽기 전용 조사/후속 검토. 기존 잠금·저장 키·버전·밸런스는 유지한다.
게임 규칙 테스트와 실제 화면 조작 검증은 구분한다.

### 수정

| 재현 | 원인 | 변경 |
|---|---|---|
| 도시락 뚜껑을 누른 직후 메뉴→타이틀로→이어하기 | 900ms 콜백이 표시 화면을 기준으로 정산을 취소하고 닫힌 뚜껑만 남김 | 같은 게임의 아침이면 화면과 무관하게 한 번 처리·저장; 새 게임으로 바뀌면 이전 콜백 무시 |
| 결산의 크게 보기→브라우저 뒤로 | 사진용 기록 없이 게임 기록이 소모됨 | 사진에 별도 기록, 뒤로는 사진만 닫고 결산/앨범 유지 |

### 확인한 범위

- 390×700 브라우저에서 새 게임→소개→이름→식사→이벤트→결산과 사진 확대/닫기.
- 뚜껑 처리 중 타이틀 이탈 후 이어하기: 저녁으로 진행, 반찬값 30→25 한 번만 차감.
- 사진 뒤로는 결산 유지, 앨범 안 사진 뒤로는 앨범 유지. 사진을 탭해서 닫기도 확인.
- `index.html`→루트→이어하기→메뉴→타이틀→뒤로 1회가 `index.html`로 복귀.
- 기존 저장을 새 빌드로 불러와 이름/나이/돈/하트(40)/도감 보존 및 저녁 모순 문구 제거 확인.
- 기존 `npm test` 27개와 2000판 자동 플레이, `npm run build`, `npm run build:preview` 통과.
- 1살부터 20살까지 화면 조작으로 한 판 완료: 인디 밴드 보컬 엔딩, 다시 키우기→1살 이름 선택→메뉴→타이틀 정상 복귀. 하트 99·발견한 엔딩/도감 유지. 모든 엔딩을 확인한 것은 아니다.
- Android debug 빌드(153 tasks)와 apksigner 검증 통과. 브라우저 뒤로 검증을 Android 실기기 뒤로 검증으로 간주하지 않는다.

### 남은 검증·관찰

- 실제 iPhone 터치·백그라운드 전환, Android 하드웨어 뒤로, iOS native는 별도 확인.
- 아침의 선택 중인 재료/남은 시간과 이벤트 결과 문구는 재접속 시 복원되지 않는 기존 동작이 있다. 저장 정책을 정해 별도 수정할 후속 항목이다. 이미 완료한 식사·돈·하트 저장과 구분한다.
- 모든 이벤트/엔딩, 미니게임의 모든 위험/성공 분기, 장시간·오디오 실기기 테스트까지 완료한 것은 아니다.
