# 아이 캐릭터 부품 (도트 원본)

코드가 그린 아이 캐릭터를 **층(부품)별 PNG**로 뽑아 둔 폴더예요. 사람이 손으로 다듬기 위한 원본입니다.

```
npm run export:parts   # 이 폴더를 다시 만든다 (코드 그림 기준)
```

## 고치는 법
1. 이 폴더의 PNG를 도트 편집기(무료: Pixelorama, 유료: Aseprite)로 엽니다. `_preview/` 는 8배 확대본이라 보기용이에요.
2. **캔버스 크기(24×40)와 위치는 그대로** (발끝은 모든 단계에서 38번째 줄) 두고 그림만 고칩니다. 배경은 투명, 외곽선은 그리지 않아요 (게임이 마지막에 한 번에 씌웁니다).
3. 고친 파일을 **같은 이름**으로 `src/assets/pixel/parts/` 에 넣습니다.
4. 게임을 다시 띄우면 그 부품만 손그림으로 바뀌고, 나머지 부품·외곽선·옷 색 바꾸기·소품·걷기 흔들림은 코드가 그대로 처리해요.

## 파일 이름 규칙
`<방향>-<나이>-<성별>-<부품>.png`
- 방향: `front`(정면), `side`(옆모습, 오른쪽을 봄)
- 나이(성장 단계): `1` 아기 · `2` 아장아장 · `4` 유치원 · `7` 초등 저학년 · `11` 고학년 · `15` 중학생 · `18` 고등학생 · `19` 스무 살 / 성별: `boy`, `girl`
- 부품: `legs`, `outfit`, `head`(피부·목·귀), `hair`(머리카락·핀), `face-<표정>`(`neutral`, `happy`, `yuck`, `sad`, `surprise`), `face-<표정>-blink`(눈 감은 프레임)
- 옆모습 걷기는 프레임마다: `legs-f0` ~ `legs-f7`, `outfit-f0` ~ `outfit-f7`

## 지켜 주세요
- 옷 색 바꾸기는 **정해진 옷 색**을 다른 색으로 바꾸는 방식이라, 옷을 칠할 때 원래 팔레트의 옷 색(흰 티 `#fdf6e8`·`#e8dcc6`, 노란 원피스 `#f5c94a`·`#d9a933`, 교복 `#36456b`·`#283452`)을 쓰면 색 바꾸기가 계속 적용돼요.
- 머리카락 색도 원래 색을 쓰면 나중에 머리색 바꾸기를 붙이기 쉬워요.
